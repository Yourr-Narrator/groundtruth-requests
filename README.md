# GroundTruth requests

Public contact point for [GroundTruth](https://groundtruth-ivory.vercel.app), the site that tracks dated builder quotes and K-RERA facts for residential projects.

Open an issue here to:

- **Ask permission** to reuse GroundTruth figures or the dataset (see the [terms of use](https://groundtruth-ivory.vercel.app/terms)).
- **Report a wrong figure** on a project page. Link the page and, if you can, the source that shows the right figure.
- **Ask for a quote or record to be removed**, for example one you posted yourself.

Please don't post personal details (phone numbers, addresses, booking documents) in an issue: issues here are public.
